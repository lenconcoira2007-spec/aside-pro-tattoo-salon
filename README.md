# ASIDE PRO Tattoo Salon

Адаптивный веб-сайт тату-салона с каталогом услуг, портфолио, отзывами и формой заявки.

- **GitHub:** https://github.com/lenconcoira2007-spec/aside-pro-tattoo-salon
- **Публикация GitHub Pages:** https://github.com/lenconcoira2007-spec/aside-pro-tattoo-salon/actions
- **Автоматизированные проверки:** https://github.com/lenconcoira2007-spec/aside-pro-tattoo-salon/actions

## Возможности сайта
- Главная страница с услугами, преимуществами, портфолио, отзывами, FAQ и контактами.
- Отдельные страницы татуировки, пирсинга и лазерного удаления.
- Адаптивная навигация для мобильных устройств.
- Форма заявки с обязательными полями и проверкой введённых данных.
- Загрузка перечня услуг и сохранение заявки в IndexedDB.
- Просмотр структуры хранилищ, индексов и текущих записей.

## База данных
Модуль записи использует IndexedDB — встроенное хранилище браузера. База называется `aside-pro-tattoo-db`, версия 1. Она содержит хранилища `services` и `appointments`; связь между ними реализована через поле `serviceId`.

**Область хранения:** записи доступны только в том браузере, профиле и на том адресе сайта, где они созданы. Форма не отправляет заявку сотрудникам салона, не обеспечивает синхронизацию между устройствами и не подтверждает забронированное время. Для централизованной обработки заявок потребуется серверная БД и API.

## Проверка
Автоматизированные сценарии Playwright проверяют страницы сайта, загрузку услуг, валидацию формы, создание, чтение и удаление записи, структуру IndexedDB, адаптивность и мобильную навигацию. Фактические результаты и снимки находятся в `docs/verification-results.md` и `screenshots/auto/`.

## Локальный запуск
Откройте папку проекта в VS Code и запустите через локальный HTTP-сервер, например Live Server. Не используйте `file://`: проект использует JavaScript ES-модули и IndexedDB.

## Перед использованием с реальными клиентами
Проверьте официальный адрес и контакты, цены, достоверность отзывов и права на фотографии. Для приёма реальных заявок требуется серверное хранение, защищённый API и соответствующая политика обработки персональных данных.
