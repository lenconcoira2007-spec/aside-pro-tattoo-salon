# ASIDE PRO Tattoo Salon

Учебный проект веб-сайта тату-салона и документации по теме «Разработка документации проекта software с использованием базы данных (BD)».

## Содержание

- `docs/` — техническое задание, проектная документация, модель данных, карта сайта, диаграммы, тест-план и реестр доказательств.
- `database/` — описание учебной базы IndexedDB.
- `tests/` — страница демонстрации тестовых заявок.
- `screenshots/` — папки для реальных скриншотов этапов работы.
- `.github/workflows/pages.yml` — публикация сайта через GitHub Pages.

## Важное замечание о базе данных

Учебная форма записи использует IndexedDB в браузере. Это локальное хранилище профиля браузера, а не серверная общая база данных. Заявки не передаются владельцу салона и не синхронизируются между устройствами. Для реальной эксплуатации требуется серверная БД и API.

## Локальный запуск

Откройте проект через локальный HTTP-сервер (например, VS Code Live Server), а не через `file://`. Форма записи расположена на `registration.html`; тестовая демонстрация базы — `tests/database-demo.html`.

## Публикация

Workflow размещён в `.github/workflows/pages.yml`. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации. После успешного запуска адрес появится в разделе Pages.

## Проверка и скриншоты

Перед защитой выполните сценарии из `docs/test-plan.md` и сохраните настоящие снимки экранов в соответствующие каталоги `screenshots/`. Не выдавайте планы или макеты за доказательство фактического выполнения.


## Загрузка полного архива в GitHub

Репозиторий: https://github.com/lenconcoira2007-spec/aside-pro-tattoo-salon. Интеграция GitHub подключена. Чтобы передать все исходные изображения и документы DOCX, один раз загрузите ZIP-файл ASIDE_PRO_Tattoo_Salon_Project.zip в корень репозитория через **Add file → Upload files** и выполните **Commit changes**. Workflow распакует архив, добавит полный набор файлов отдельным коммитом и запустит публикацию. Подробности — в docs/github-upload.md.
