# ASIDE PRO Tattoo Salon

Адаптивный веб-сайт тату-салона с каталогом услуг, портфолио, отзывами и формой заявки.

## Возможности
- Страницы услуг: татуировки, пирсинг и лазерное удаление.
- Портфолио, преимущества студии, отзывы, FAQ и контакты.
- Адаптивное мобильное меню.
- Форма заявки с проверкой обязательных полей.
- Справочник услуг и локальное сохранение заявок в IndexedDB.
- Просмотр структуры хранилищ, ключей, индексов и текущих записей.

## База данных
Используется IndexedDB: `aside-pro-tattoo-db`, версия 1. Хранилища: `services` и `appointments`. Связь 1:N реализована через `appointments.serviceId` → `services.id`; индексы заявок: `byService`, `byCreatedAt`, `byStatus`.

**Ограничение:** IndexedDB хранит записи только в текущем браузере, профиле и на текущем origin. Заявки не отправляются сотрудникам студии и не синхронизируются между устройствами. Для централизованной обработки требуется серверная БД и API.

## Локальный запуск
Откройте папку проекта в VS Code через локальный HTTP-сервер (например, Live Server). Не используйте `file://`: проект использует JavaScript ES-модули и IndexedDB.

## Перед использованием с реальными клиентами
Проверьте официальный адрес и контакты, цены, отзывы и права на фотографии. Для приёма реальных заявок требуется серверное хранение, защищённый API и соответствующая политика обработки персональных данных.
