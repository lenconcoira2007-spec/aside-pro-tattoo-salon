# Учебная база данных ASIDE PRO

## Реализация

Используется IndexedDB — встроенное браузерное хранилище, доступное через JavaScript. Код находится в `../JS/booking-db.js`.

- База: `aside-pro-tattoo-db`.
- Версия: `1`.
- Хранилища: `services`, `appointments`.
- Форма: `../registration.html` и `../JS/booking.js`.
- Демонстрация чтения и удаления: `../tests/database-demo.html`.
- Модель данных: `../docs/database-design.md` и `../docs/er-diagram.mmd`.

## Ограничение

Это не SQL Server/MySQL и не серверная БД. Заявки доступны только в текущем браузере, профиле и на текущем origin. Данные не отправляются в салон и не синхронизируются между устройствами. Не вводите реальные персональные данные.
