# База данных ASIDE PRO Tattoo Salon

## Реализация

Для локального хранения заявок используется IndexedDB — встроенное браузерное хранилище, доступное через JavaScript. Код находится в `JS/booking-db.js`.

- Имя БД: `aside-pro-tattoo-db`, версия 1.
- Хранилища: `services` и `appointments`.
- Связь: `appointments.serviceId` → `services.id`.
- Индексы заявок: `byService`, `byCreatedAt`, `byStatus`.
- Операции: инициализация, чтение услуг, создание заявки, чтение и удаление записей.

Данные доступны только в текущем браузере и на текущем адресе сайта. Они не передаются сотрудникам салона и не синхронизируются с другими устройствами. Для централизованного приёма заявок необходим серверный API и серверная база данных.
