# Скриншоты-подтверждения проекта

Скриншоты добавляются только после реального выполнения действия. Не вставлять макеты, сгенерированные изображения или фрагменты диаграмм вместо снимков GitHub/браузера.

| Папка | Что фиксировать | Примеры имён |
|---|---|---|
| `01_source_site/` | Исходный сайт, страницы и исходная форма | `01_homepage.png`, `02_registration_before.png` |
| `02_github/` | Репозиторий, дерево файлов, коммиты, ветка, PR | `01_repository.png`, `02_file_tree.png`, `03_commits.png`, `04_pull_request.png` |
| `03_database/` | Реальная IndexedDB, stores, индексы и тестовая запись | `01_database_schema.png`, `02_services_store.png`, `03_appointments_store.png` |
| `04_tests/` | Валидация, сохранение после перезагрузки, удаление, адаптивность | `01_validation.png`, `02_persistence.png`, `03_delete.png`, `04_mobile.png` |
| `05_publication/` | Успешный GitHub Actions и опубликованный сайт | `01_actions_success.png`, `02_published_site.png` |

## Как сделать снимок в Windows 10

1. Открыть нужную страницу/вкладку и разместить на экране важную часть результата.
2. Нажать `Win + Shift + S` и выделить область.
3. Сохранить PNG с именем из таблицы в соответствующую папку.
4. Убедиться, что в снимке нет паролей, токенов и реальных персональных данных.
5. Внести имя снимка в `docs/evidence-register.md` и добавить ссылку на него в отчёт.

Каталог `screenshots/` пока является реестром будущих доказательств. GitHub-снимки появятся после создания репозитория; снимки БД — после запуска проекта в браузере пользователя.
