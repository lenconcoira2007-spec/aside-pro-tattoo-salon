# Проектирование базы данных (BD)

## 1. Технология
Для статической учебной версии применяется IndexedDB — встроенное объектное хранилище браузера. Оно позволяет продемонстрировать CRUD без отдельного сервера. Это не SQL Server/MySQL и не централизованная серверная база.

Имя: aside-pro-tattoo-db. Версия: 1.

## 2. Хранилище services

| Поле | Тип | Ключ | Назначение |
|---|---|---|---|
| id | string | PK | Идентификатор услуги |
| name | string | — | Название |
| priceLabel | string | — | Отображаемая цена |
| active | boolean | индекс byActive | Доступность |
| sortOrder | number | — | Порядок в форме |

## 3. Хранилище appointments

| Поле | Тип | Ключ | Назначение |
|---|---|---|---|
| id | number | PK, autoIncrement | Номер заявки |
| clientName | string | — | Имя тестового клиента |
| contact | string | — | Телефон или мессенджер |
| serviceId | string | byService | Выбранная услуга |
| comment | string | — | Комментарий |
| preferredDate | string | — | Желаемая дата |
| preferredTime | string | — | Желаемое время |
| createdAt | ISO 8601 string | byCreatedAt | Дата создания |
| status | string | byStatus | Статус, начальное значение new |

## 4. Связь
services (1) — (N) appointments. Одна услуга может встречаться во многих заявках. В IndexedDB внешний ключ не обеспечивается СУБД: приложение проверяет наличие и активность выбранной услуги до записи.

## 5. Операции
Открытие БД; создание object stores при первом запуске; заполнение справочника услуг; чтение услуг; валидация; добавление заявки транзакцией; чтение заявок; удаление одной или всех тестовых заявок.

## 6. Ограничения
Данные существуют только в текущем браузере, профиле и origin. Они не синхронизируются с другими устройствами и могут быть удалены очисткой данных сайта. Форма не отправляет заявку владельцу салона и не подтверждает визит. Для реального использования потребуется серверная БД, API и защищённая административная часть.
