## Проверки, которые ещё нельзя считать пройденными

- Реальное открытие страниц в браузере Windows 10.
- Создание записи в IndexedDB, сохранение после перезагрузки и удаление.
- Проверка мобильного меню и адаптивности на устройстве пользователя.
- Создание GitHub-репозитория, коммиты, ветки, Pull Request и запуска workflow.
- Запуск GitHub Actions и проверка GitHub Pages.

Попытка автоматического браузерного запуска в текущем рабочем окружении остановлена политикой браузера (`ERR_BLOCKED_BY_ADMINISTRATOR`) для внешних и локальных адресов. Это ограничение относится к текущей среде выполнения, а не является результатом тестирования сайта в Chrome/Edge на ноутбуке пользователя. Поэтому функциональные результаты не подменяются предположениями. Их нужно снять в локальном Chrome/Edge пользователя после распаковки архива.

## Как закрыть оставшиеся проверки

1. Распаковать ZIP в отдельную папку.
2. Открыть её в VS Code и запустить сайт через Live Server либо другой локальный HTTP-сервер.
3. Открыть `registration.html`, отправить вымышленную заявку и проверить IndexedDB через DevTools → Application → IndexedDB.
4. Открыть `tests/database-demo.html`, проверить чтение и удаление тестовой заявки.
5. Создать GitHub-репозиторий, загрузить проект, выполнить публикацию и сделать реальные скриншоты по `docs/evidence-register.md`.
