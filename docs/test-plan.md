# План тестирования ASIDE PRO Tattoo Salon

Тестировать через HTTP/HTTPS, не через file://. В журнал вносить фактические браузер, версию, ОС, URL и дату.

| ID | Действие | Ожидаемый результат |
|---|---|---|
| TC-01 | Открыть шесть страниц | Все страницы загружаются |
| TC-02 | Проверить навигацию | Все ссылки ведут к нужным страницам/секциям |
| TC-03 | Проверить CSS, JS и изображения | Нет ошибок загрузки ресурсов |
| TC-04 | Отправить пустую форму | Обязательные поля блокируют отправку |
| TC-05 | Ввести короткое имя | Значение отклоняется |
| TC-06 | Ввести короткий контакт | Значение отклоняется |
| TC-07 | Отправить валидную тестовую заявку | Появляется сообщение о локальном сохранении |
| TC-08 | Обновить страницу/открыть demo | Запись сохраняется в текущем профиле |
| TC-09 | Удалить одну запись | Запись исчезает |
| TC-10 | Удалить все тестовые записи | Список пуст |
| TC-11 | Проверить мобильное меню | Меню доступно и корректно переключается |
| TC-12 | Проверить 320/390/768/1024/1440 px | Нет горизонтальной прокрутки |
| TC-13 | Проверить GitHub Actions | Workflow завершён успешно |
| TC-14 | Открыть GitHub Pages | Страницы и ресурсы доступны |

Для тестов использовать вымышленные данные (например, Test User, test@example.invalid). Не вводить реальные телефоны/имена. Для каждого теста записать Passed/Failed/Blocked/Not run, наблюдение и ссылку на реальный скриншот.
