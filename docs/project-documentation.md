# Проектная документация ASIDE PRO Tattoo Salon

Редакция 1.0 · 16 ноября 2026 г.

## 1. Назначение
Учебный сайт тату-студии с описанием татуировок, пирсинга и лазерного удаления, портфолио, преимуществами, отзывами, FAQ, контактами и формой заявки.

## 2. Исходное состояние
Исходный ZIP содержал шесть HTML-страниц, общий CSS, JS мобильной навигации и изображения. Исходная форма вызывала alert и не сохраняла данные. Серверной части, API, SQL и IndexedDB в исходном архиве не обнаружено. См. analysis-before-change.md.

## 3. Доработка учебной копии
Добавлены обработчик формы, слой IndexedDB, справочник услуг, хранилище заявок и демонстрационная страница просмотра/удаления. Форма сообщает о локальном сохранении и не называет заявку подтверждённой записью.

## 4. Страницы
index.html — главная; tattoo.html — татуировки; piercing.html — пирсинг; removing.html — удаление; feedback.html — отзывы; registration.html — форма заявки.

## 5. Архитектура
Статический фронтенд HTML/CSS/JavaScript ES modules. JS/booking-db.js отвечает за IndexedDB; JS/booking.js обрабатывает форму; tests/ содержит учебную страницу управления тестовыми заявками.

## 6. Модель данных
БД aside-pro-tattoo-db, версия 1. Хранилища services и appointments. Связь 1:N моделируется через appointments.serviceId. См. database-design.md и er-diagram.mmd.

## 7. Запуск
Открывать через локальный HTTP-сервер (например, Live Server в VS Code), не через file://.

## 8. Проверка
План — в test-plan.md, текущий статус — в verification-results.md, доказательства — в evidence-register.md. Функциональные результаты заполняются после реального браузерного теста.

## 9. Ограничения и риски
IndexedDB локальна для браузерного профиля и origin. Заявки не видны сотрудникам студии и не синхронизируются. В исходном HTML есть адрес в Москве, номер с кодом +7 и email TattooSalon@mail.ru; достоверность не подтверждена. До коммерческого использования нужно проверить контакты, цены, отзывы и права на изображения.
